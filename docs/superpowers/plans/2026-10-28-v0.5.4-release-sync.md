## Pitfall Prevention Checklist

- Frontmatter slug must explicitly include the version dot notation:
  - Chinese: `slug: releases/v0.5.4`
  - English: `slug: en/releases/v0.5.4`
- Required sections in release notes: `摘要`, `已验证范围`, `已知限制`, `升级`, `回退`, `验证`, `撤回`.
- No forbidden claims: `OpenWrt 已支持` or `非零 SO_MARK 已验证` are strictly rejected by `validate-release-metadata.mjs`.
- Security boundaries: No real IPs (only RFC 5737 / RFC 3849), no real keys (only `REPLACE_WITH_*`).
- Parity: Every document in `src/content/docs/` must have a corresponding English version in `src/content/docs/en/`.
- Fine-grained commits: Each distinct logical unit has its own atomic commit for easy cherry-picking.

## 摘要

`frp-tun v0.5.2` 重点实现动态网络环境下 WAN 地址改号自动感知、P2P 候选平稳晋升恢复以及自适应平滑回切。

### 主要改进特性

1. **Netlink 地址与出口指纹观察**：动态订阅 Linux Netlink 地址与路由事件，提取出口网卡索引及默认/直连路由指纹，支持 250ms 防抖与 30s 周期兜底，并支持优雅降级；
2. **按族网络代次与资源隔离**：引入独立 NetworkEpoch 与租约计数，IPv4/IPv6 环境变更独立递增，确保连接平滑过渡且失效资源有界回收（每族最多 1 个退役资源）；
3. **不可变代次栅栏**：异步 STUN 探测、端口映射与 QUIC 握手均绑定不可变代次，杜绝跨代旧结果污染新候选集合；
4. **候选数据面探针与单拥有者交接**：Stream 候选通道采用独立 Nonce Ping/Pong 在业务流上验证双向连通；Supervisor 发起 Token 化单拥有者交接，旧中继保留 5 秒只收不发窗口避免倒换丢包；
5. **WireGuard 非对称保活策略**：区分 Visitor 与 Proxy 角色，仅发起方配置持久保活，消除双端并发握手交叉碰撞缺陷；
6. **跨版本兼容性保证**：补充与 v0.5.1 历史版本的受控互通夹具，确保混合版本组网平滑兼容。

## 升级

1. 备份当前网关上的配置文件（如 `/etc/frp-tun/config.toml`）；
2. 停止当前守护进程：
   ```bash
   systemctl stop frp-tun
   ```
3. 替换二进制并赋予执行权限：
   ```bash
   chmod +x frp-tun_v0.5.2_amd64
   mv frp-tun_v0.5.2_amd64 /usr/local/bin/frp-tun
   ```
4. 启动服务并检查状态：
   ```bash
   systemctl start frp-tun
   ```

---

## 回退

若在升级后发现网络异常或打洞受阻：
1. 停止服务：`systemctl stop frp-tun`；
2. 将备份的历史版本二进制恢复至 `/usr/local/bin/frp-tun`；
3. 清理残存策略路由与接口（如有）：`ip link delete frp-tun:0 2>/dev/null || true`；
4. 重新启动历史版本守护进程。

若发现重大安全漏洞或内核奔溃缺陷，项目维护者将在 Release 页面标明 `REVOKED — DO NOT USE`，下架对应二进制资产，并通过 [SECURITY.md](https://github.com/elkpi/frp-tun-page/blob/main/SECURITY.md) 发布安全修复通告。

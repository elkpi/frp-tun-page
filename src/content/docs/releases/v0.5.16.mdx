## 摘要

- **auto 自动切换数据面**：新增站点级 `site.data_plane = "auto"`。每个对端在直连（QUIC）、按配置顺序的私有 Hub、公共 STCP 之间自动切换：直连优先；连续 3 次无可用直连后回落；直连稳定 60 秒且距上次回落超过 5 分钟后才升回；更优先的 Hub 恢复后立即切回。运行中不能热切换数据面或 `site.hub_unencrypted`，需要先 `down` 再启动。
- **私有 Hub 可选明文**：`site.hub_unencrypted` 缺省为 `false`，仅在 `auto` / `tun-quic` 下生效。两端都打开时，私有 Hub 承载不套 WireGuard 的 IP 包，端到端认证、序号与重放窗口保留；任一端未打开仍走同一 Hub 的 WireGuard 载荷；公共 STCP 永远承载 WireGuard。
- **按对端钉住承载**：新增 `frp-tun pin --peer <id> --target direct|relay|clear`，按对端钉住直连或中继，跳过失败阈值和回切抑制期，但仍需双方三次握手；`clear` 解除钉住并留在当前路径。命令只写 journal 并开始协商，不等待对端确认，也不因对端离线而失败。
- **混合部署与纯 Hub 节点**：`auto` 与固定 `wg-quic` 收敛到共享 STCP 中继；已被认证的旧版直连仅用于识别，不再承载业务。被其他对端 `private_relay.hubs` 引用、自身不配置中继或回落能力的纯 Hub 节点不参与本站转发与路由；Hub 节点的中继授权仍由 `private_relay.pairs` 提供。
- **IPv6 动态前缀加固**：动态前缀同步在直连走 QUIC 控制流、WireGuard 中继走 SyncPort、明文 Hub 走已认证协商通道；通告带签名快照序号与租期上限，迟到的快照不能恢复已撤销的前缀，到期撤销数据路由。`peer.ipv6.sync_port` 缺省改为按站点对派生，双 `auto` 通过签名信令交换实际绑定的端口。
- **升级注意**：与固定模式或旧版本互通时，`sync_port` 需两端显式配置相同的可用端口（旧版默认统一 51830，新版按站点对派生）；详见上游 docs/compatibility.md §6–7。[v0.5.15](/releases/v0.5.15/) 及更早版本已验证的能力和结论继续有效。

- 本地环回（原版 frps v0.71.0）E2E 全部通过：双栈直连、STCP 冷回落、加密与明文私有 Hub、固定 tun-quic Hub、双 Hub 故障转移与回切、journal 写盘故障重启恢复、`auto` × 固定 WG 双向收包（两种拨号角色）、三站点经 WG/STCP 并发同步 IPv6 前缀与撤销。

## 已知限制

- 自动切换仅依据内置的失败阈值与抑制期；需要立即固定承载时请使用 `frp-tun pin`，但仍需双方三次握手。
- `auto` 数据面或 `hub_unencrypted` 不能在运行时热切换，需先 `down` 再启动。
- 非零 `SO_MARK` 策略路由与物理 OpenWrt 设备仍未验证；本版不宣称性能收益或更低的资源占用。
- 交叉编译资产不构成特定硬件、持续高负载、非零 `SO_MARK` 或复杂 NAT 场景的兼容性保证。
- 软件不提供自动更新或可用性 SLA；请参阅 [EULA](https://github.com/elkpi/frp-tun-page/blob/main/EULA.md)。

## 升级

在维护窗口备份现有配置和旧版二进制，确认独立回退路径。下载匹配架构的二进制并核对摘要后，停止服务、替换二进制并重启，然后运行 `frp-tun doctor` 检查状态。已有启用 journal 时，重启恢复已提交配置；需要更改配置时使用 `frp-tun apply`。如需试用 `auto` 或更改 `hub_unencrypted`，先执行 `down`，确认配置满足中继路径要求后再启动。与固定模式或旧版本互通时，两端显式配置相同的可用 `sync_port`。详见[升级与回退](/operations/upgrade-rollback/)及[配置参考](/configuration/full-reference/)。

## 回退

停止服务，恢复备份的旧版二进制，再启动并检查状态。配置回退和二进制回退并非同一操作；切换回旧默认 `sync_port` 时需两端同时改回 51830，操作前请核对目标旧版的发行说明及其 journal 行为。

## 撤回

如发现重大安全或稳定性问题，维护者将在公开 Release 页面标记撤回，并按 [SECURITY.md](https://github.com/elkpi/frp-tun-page/blob/main/SECURITY.md) 发布通告。

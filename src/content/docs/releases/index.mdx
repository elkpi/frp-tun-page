在此查阅 `frp-tun` 历次公开发行版本的二进制下载地址、SHA256 校验清单与验证记录：

- [v0.5.13 (当前稳定版本)](/releases/v0.5.13/)：用户态 WireGuard 与真实 QUIC 双端链路归因；接收方向 1400B 的 CPU 改善 9.42%，未达 10% 门槛，生产默认仍为批量接收。
- [v0.5.12](/releases/v0.5.12/)：修复批量 sendmmsg/recvmmsg 负计数回退，Endpoint 批写按调用复用缓冲；生产默认仍为批量接收，接收模式对照只是诊断样本。
- [v0.5.11](/releases/v0.5.11/)：LoopbackBind 与 Endpoint 批量收发、惰性过期；公平基准显示 CPU 收益仅在 1400B 档有实证，heap 每包对象数增加。
- [v0.5.10](/releases/v0.5.10/)：Go 性能优化第二阶段第一轮——发送缓冲复用与出站直入池化缓冲，以及真实 QUIC 基准与 CPU profile 归因。
- [v0.5.9](/releases/v0.5.9/)：Go 性能优化第一阶段——帧收发快速路径与零分配 loopback IO、活动泵事件驱动管理，以及受控负载基准。
- [v0.5.8](/releases/v0.5.8/)：动态 MTU 观察器的会话切换语义修复，以及真机 CPU 测量口径注记。
- [v0.5.7](/releases/v0.5.7/)：按需性能采样、自适应 datagram 大小与隧道 MTU，以及恢复和生命周期修复。
- [v0.5.6](/releases/v0.5.6/)：重启恢复已提交配置，`apply` 失败回滚到上一代，并拒绝不完整 journal。
- [v0.5.5](/releases/v0.5.5/)：控制面信令收敛、TCP MSS Clamping、Doctor 双模全景诊断与 OpenWrt UCI/LuCI 全栈集成。
- [v0.5.4](/releases/v0.5.4/)：空候选恢复循环抑制、网络纪元退避防护与准备日志降噪。
- [v0.5.3](/releases/v0.5.3/)：自研 QUIC 直连建联方向对称化、端口块 NAT 修复、流握手首帧防死锁与全链路 DialRole 可观测性。
- [v0.5.2](/releases/v0.5.2/)：WAN 改号自动感知与恢复、不可变代次栅栏、数据面单拥有者交接与 WireGuard 非对称保活。
- [v0.5.1](/releases/v0.5.1/)：STUN 并发竞速打洞、蜂窝 CGNAT 端口预测优化、新增 32 位 ARM (armv7) 支持与高可用链路恢复。

## 摘要

`frp-tun v0.5.1` 重点优化了 STUN/NAT 发现、弱网恢复路径选择和边缘设备稳态探测能力。

### 主要改进特性

1. **STUN 并发竞速打洞**：DNS 与网络响应共享 500ms 发现预算，收集满 3 个独立样本后极速早停；
2. **DNS 防抖与冷却**：5 分钟本地 DNS 缓存、30 秒失败冷却，消除重复解析负担；
3. **蜂窝 CGNAT 容差预测**：自适应识别等差端口分配规律，执行 36～40 个目标端口的并发靶向预测打洞；
4. **链路无感晋升与快速恢复**：冷启动与链路恢复时并行尝试获准路径；优先保障通信恢复，再按路径等级、地址族偏好平滑晋升；
5. **首选私有 Hub 防抖回切**：引入 30 秒观察期与 6 次连续成功阈值，防止在临界网络下反复震荡；
6. **稳态低功耗运行**：P2P 直连通道稳定后自动降低探针频次，减轻路由器 CPU 与系统负荷。

## 升级

1. 备份当前网关上的配置文件（如 `/etc/frp-tun/config.toml`）；
2. 停止当前守护进程：
   ```bash
   systemctl stop frp-tun
   ```
3. 替换二进制并赋予执行权限：
   ```bash
   chmod +x frp-tun_v0.5.1_amd64
   mv frp-tun_v0.5.1_amd64 /usr/local/bin/frp-tun
   ```
4. 启动服务并检查状态：
   ```bash
   systemctl start frp-tun
   ```

---

## 回退

若在升级后发现网络异常或打洞受阻：
1. 停止服务：`systemctl stop frp-tun`；
2. 将备份的历史版本二进制恢复至 `/usr/local/bin/frp-tun`；
3. 清理残存策略路由与接口（如有）：`ip link delete frp-tun:0 2>/dev/null || true`；
4. 重新启动历史版本守护进程。

## 撤回

若发现重大安全漏洞或内核奔溃缺陷，项目维护者将在 Release 页面标明 `REVOKED — DO NOT USE`，下架对应二进制资产，并通过 [SECURITY.md](https://github.com/elkpi/frp-tun-page/blob/main/SECURITY.md) 发布安全修复通告。

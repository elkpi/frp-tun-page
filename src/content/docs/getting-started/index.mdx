> **适用版本：技术预览。** 官方多架构预编译二进制包可从 [发行说明](/releases/) 页面校验并获取；软件不包含自动更新。

frp-tun 是一个闭源站点到站点网关。它把 WireGuard overlay 与 frp signalling/carrier 分开：前者负责端到端加密，后者只承载已经加密的 UDP 数据报。

## 部署前提

- 两端都有可控的 Linux 或 OpenWrt 网关；
- 运维者能够审查策略路由、nftables 与接口恢复行为；
- 可以在维护窗口中手动升级并回退；
- 不将 WireGuard 私钥、frp token、内部地址或拓扑发布到公开支持渠道。

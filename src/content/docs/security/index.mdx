## 核心安全与免责边界

1. **合法合规义务**：本软件仅供正当网络测试与研究用途。严禁用于任何破坏计算机系统或违法网络活动，违者独立承担全额法律责任，开发者不承担连带责任。详见 [EULA 与免责声明](https://github.com/elkpi/frp-tun-page/blob/main/EULA.md)。
2. **私钥隔离**：WireGuard 私钥仅留存于网关本地，绝不经由 carrier 传输，亦不得提交至公开 Issue。
3. **策略路由沙箱**：接口启动前预装 guard blackhole 路由，防止加密通道中断时数据泄漏。
4. **安全披露渠道**：请遵照负责任披露守则，将安全问题私下提交至 `security@elkpi.com`。

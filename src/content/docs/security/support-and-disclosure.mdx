## 1. 私密安全漏洞披露

若您发现了潜在的安全性缺陷（如加密绕过、未加密泄漏、特权越界等），请严格遵守负责任披露原则：

- **发送报告至**：`security@elkpi.com`；
- **禁止公开**：**严禁**在 GitHub Issues、Discussions 或社交平台公开漏洞细节；
- **报告内容**：请提供影响版本、操作系统与架构、危害说明及最小化脱敏复现步骤；
- **时效承诺**：我们将在 48 小时内确认邮件送达，并在评估完成后启动补丁制作或版本撤回流程。

## 2. 公开支持与防泄密守则

常规使用咨询与已脱敏的 Bug 报告请使用 [GitHub Issues](https://github.com/elkpi/frp-tun-page/issues) 或 [GitHub Discussions](https://github.com/elkpi/frp-tun-page/discussions)。

在公开发布任何内容前，您**必须**自查并移除以下敏感信息：
1. **WireGuard 私钥**：严禁出现真实的 `PrivateKey`；
2. **frp 凭据**：严禁出现真实 `token`、`shared_secret`；
3. **真实网络端点**：所有 IP 地址必须替换为文档保留地址（如 `198.51.100.x`），域名替换为 `example.com`；
4. **系统日志**：截图中不得包含内网主机名、企业资产或私有拓扑信息。

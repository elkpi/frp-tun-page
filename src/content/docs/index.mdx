## 先判断是否适合部署

frp-tun 面向同时管理 Linux 或 OpenWrt 网关、WireGuard overlay 与 frp underlay 的运维者。WireGuard 数据包先在本地加密，再交由优先的 P2P 路径或受控的 STCP 回退路径承载。

部署前请确认你能维护 root/CAP_NET_ADMIN 权限、策略路由、nftables 与独立的回退流程。未完成硬件和公网验证的平台会明确保持“实验性”状态。

---

### 1. 双栈与 QoS 推荐配置示例

```toml
schema_version = 1

[site]
id = "site-a"
networks = ["198.51.100.0/24"]
tunnel_address = "198.51.100.1/32"
role = "proxy"
allow_relay = true

[site.ipv6]
enabled = true
tunnel_address = "2001:db8:1::1/128"

[peer]
id = "site-b"
networks = ["198.51.200.0/24"]
tunnel_address = "198.51.100.2/32"
role = "visitor"
allow_relay = true
public_key = "REPLACE_WITH_SITE_B_PUBLIC_KEY"

[peer.ipv6]
enabled = true
tunnel_address = "2001:db8:1::2/128"

[frp]
server_addr = "relay.example.com"
server_port = 7000
token = "REPLACE_WITH_FRP_TOKEN"
shared_secret = "REPLACE_WITH_SHARED_SECRET"
tls = true
transport_protocol = "quic"

[wireguard]
mode = "auto"
private_key = "REPLACE_WITH_SITE_A_PRIVATE_KEY"

[forwarding]
authorize_enable = true
mode = "nftables"

[p2p]
prefer_family = "ipv4"
listen_port = 51821
family_standby = true

[p2p.qos]
enabled = true
probe_interval = "1s"
probe_timeout = "2s"
rtt_ratio_threshold = 1.3
rtt_min_diff = "15ms"
loss_diff_threshold = 0.05
switchback_holddown = "30s"
```

---

### 原理说明

- **协议族偏好 (`prefer_family`)**：
  - 设置为 `ipv4` 时，打洞状态机优先尝试 IPv4 直连通道，成功后将其设为主通信链路；
  - 若 IPv4 打洞受阻或运营商丢包剧烈，在开启 `family_standby = true` 的情况下，系统会立刻提升已建立好的 IPv6 直连通道；
- **STCP 中继终极兜底**：
  - 无论双栈直连情况如何，只要 `allow_relay = true`，在双向 P2P 均不可达时，流量会自动平滑通过 `server_addr` 所在的中继服务器传输，确保业务链路始终连通。
